# Project Scope

## Objective

Design and build a low-cost robotic desk lamp capable of automatically directing light toward the user's active workspace.

The system is based on an existing IKEA FORSÅ work lamp.

## Mechanical philosophy

The original spring-loaded arm mechanism will remain unchanged.

Only two degrees of freedom will be actuated:

1. Base yaw
2. Lamp-head pitch

The design should be reversible and should avoid drilling, cutting or permanently modifying the original lamp.

## Safety

The original mains-voltage electrical system of the lamp will not be modified.

All robotic electronics will operate from a separate low-voltage DC supply.

## Target use

The robot should remain practical as an everyday desk lamp rather than becoming only a demonstration platform.
