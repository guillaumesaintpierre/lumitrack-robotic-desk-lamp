# IKEA FORSÅ Characterization

## Reference lamp

IKEA FORSÅ work lamp.

## Manufacturer dimensions

| Parameter | Value |
|---|---:|
| Base diameter | 150 mm |
| Shade diameter | 120 mm |
| Overall nominal height | 350 mm |

A third-party 3D reference model is also available for preliminary geometric estimation.

Critical dimensions will be verified on the physical lamp before manufacturing custom parts.

## Experimental characterization

### Base yaw

- Rotation effort: easy to moderate
- Approximate range with joint lightly tightened: 100°
- Approximate range with joint significantly loosened: 360°
- Planned robotic range: approximately ±50°

### Head pitch

- Rotation effort: moderate
- Mechanical range: approximately -90° to +90°

## Dimensions to verify before CAD manufacturing

- Base shaft diameter
- Available base shaft height
- Arm profile width
- Arm profile thickness
- Head pivot geometry
- Servo mounting clearances
- Linkage attachment distances


## FBX reference model

The available FORSÅ reference model is a binary FBX 7.4 file.

File metadata indicates millimetre-scale model units.

The model contains:

- 64 geometry objects
- 68 model objects

Initial inspection found geometry consistent with key manufacturer dimensions, including an approximately 120 mm lamp-shade dimension.

The FBX model is therefore used for digital-twin geometry and visualization.

It is not treated as manufacturing-grade IKEA CAD data.
